# 🎨 Diseño de Interfaces Web  
### Web Interface Design

This subject focuses on **creating, styling, and optimizing user interfaces** for web applications, combining **design principles, accessibility, usability, and front-end technologies**.

It covers responsive layouts, color theory, typography, UX/UI best practices, and modern design tools.
