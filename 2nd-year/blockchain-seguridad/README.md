# 🛡️ Blockchain y Seguridad en Entornos Web  
### Blockchain & Web Security

This subject introduces **security principles in web development** and explores how **blockchain technology** can enhance data integrity, authentication, and trust in decentralized applications.

It combines theoretical foundations (cryptography, digital signatures, hashing) with practical applications (smart contracts, tokenization, and secure API communication).
