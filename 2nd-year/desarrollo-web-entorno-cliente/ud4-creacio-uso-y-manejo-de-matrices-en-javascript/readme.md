# Product Manager (JavaScript Inventory System)

A client-side inventory management application built with **JavaScript,
HTML, and CSS**.

This project was developed as part of a Web Development course to
practice advanced array methods and dynamic DOM manipulation in the
browser.

------------------------------------------------------------------------

## Features

-   Add new products to the inventory\
-   Edit existing products\
-   Delete products\
-   Filter products by name\
-   Automatically calculate total inventory value\
-   Unit tests executed in the browser console

All functionality is handled client-side without page reloads.

------------------------------------------------------------------------

## Technologies Used

-   HTML5\
-   CSS3\
-   JavaScript (ES6+)

Key JavaScript concepts implemented:

-   Arrays as primary data structure\
-   map() for dynamic table rendering\
-   filter() for deletion and searching\
-   reduce() for calculating totals\
-   Event delegation\
-   Dynamic DOM manipulation

## How to Run

1.  Clone or download the repository\
2.  Open index.html in your browser\
3.  Open Developer Tools (F12) to view unit test results in the console

------------------------------------------------------------------------

## Unit Testing

Basic unit tests are implemented using console.assert() to verify:

-   Product addition\
-   Product deletion\
-   Product filtering\
-   Total calculation

Successful execution will display:

    Pruebas unitarias completadas correctamente.

in the browser console.
